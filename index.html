Master plan

                
Week-wise Task Templates

              

              

                
                
                
              

            

            

              Every new project pre-creates one report per week from this plan. Edits here apply to
              projects created afterwards — existing projects keep the tasks they already have.
              The default plan is read from week-templates.json in the project folder.
            

            

              Stored in this browser only. Edits and deletions here save to
              localStorage immediately and cannot be undone. A normal or hard reload keeps
              your data — but clearing site data, using a private window, or opening the app from a
              different address will show an empty or different set. Use Export backup
              in Settings before making large deletions.

Users & Roles

                

              


              
Data & Backup

              

                Everything lives in this browser. Projects, weekly reports and the
                master template are stored in localStorage for
                this address only — there is no server copy.
                Reloading the page (even a hard reload) is safe. You will lose data if you clear
                site data / browsing history, use a private window, switch browser or device, or
                open the app from a different address. Deletions inside the app are immediate and
                cannot be undone. Export regularly.
